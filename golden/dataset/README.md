# Frozen dataset of the golden routes

One service day, Tuesday 2026-10-27, built by `scripts/freeze-dataset.sh` from the feeds of 2026-10-26: every TBM trip of that day, the SNCF trips that stop in the Gironde, and the streets of OpenStreetMap around the golden routes. `bikes_allowed` is left as published: the pipeline applies the bike rules in CI.
