# Story 009: Map of the itineraries

- **PRD:** E4.6 (the criteria live there, reworded: every option on one map, at the maintainer's request)
- **Status:** Done
- **Golden routes:** run: GR1 to GR6
- **Budgets touched:** NFR2: the map's island, 3 kB before it opens

## Plan

1. The engine's leg geometry decoded into each leg's path; `/api/itineraires` gives the options as GeoJSON.
2. A 60 s cache of comparisons, so the map draws what the page listed, to the minute.
3. A Vue island: "Afficher la carte" loads MapLibre, its worker and its stylesheet, then draws each option with its colour, dash and offset, and a legend.
4. ADR-0005: MapLibre and OpenFreeMap, on request.

## Notes

- MOTIS's own tiles ran out of memory at 1.6 GB twice: the tiles come from OpenFreeMap, a third party ADR-0003 now allows on request.
- MapLibre 6's worker is an ES module importing a shared chunk: in development Vite's prebundle served it without a type. It is built with `?worker&url` (format `es`) and passed to `setWorkerUrl`; the stylesheet's URL comes from `?url`, since Astro collects a dynamically imported stylesheet into the page.
- Checked in Firefox, development and production: nothing of MapLibre before the press; then the four options drawn apart; Escape closes it and gives the focus back to the button.
- `npm run check` now fails on lint warnings too (`--max-warnings 0`).

**Measure:** results page JavaScript before the map 34.3 kB compressed; the map, when opened, 437 kB more.
